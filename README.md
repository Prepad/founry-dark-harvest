# Orel Death Aura (Foundry VTT v13, D&D5e)

Пассивка волшебника: **если любой актёр падает до 0 HP в радиусе**, у владельца волшебника всплывает диалог:
- **Исцелить** → выбрать цель (все player-owned токены в радиусе, включая волшебника) + выбрать уровень (лечение = уровень × множитель)
- **Восстановить ячейку** → выбрать уровень ячейки (восстановит +1, не выше max)

## Требования
- Foundry VTT v13
- System: dnd5e
- Module: **SocketLib** (активен)

## Установка
1. Скачай ZIP релиза или установи из GitHub (после публикации).
2. Скопируй папку `orel-death-aura` в `Data/modules/`
3. Включи модуль **Orel Death Aura** и **SocketLib**.

## Настройка
`Settings → Module Settings → Orel Death Aura`

Нажми **Open Config** (Orel Death Aura — Configure) и настроь:

- **Wizard (Actor)** — выбор волшебника (Character-актёр).
- **Расходуемая особенность (Item)** — item у волшебника, у которого настроены Uses (max/value).  
  При применении пассивки тратится **1 использование**. Если Uses = 0 — диалог не откроется.
- **Radius progression (ft), JSON[20]** — радиус активации по уровням персонажа (уровень L берёт `arr[L-1]`).
- **Heal multiplier progression, JSON[20]** — множитель лечения по уровням (лечение = уровень ячейки × множитель).
- **Max heal / Max restore spell level progression, JSON[20]** — ограничение уровней в соответствующих диалогах.

> Примечание: детектор смерти работает на клиенте ГМа, а диалог показывается владельцу волшебника через SocketLib.  

## Логи

`Orel: `

## Примечания
- Детектор смерти выполняется **только на клиенте ГМа** (чтобы не было дублей).
- Диалоги отображаются **только на клиенте(ах) владельца волшебника (OWNER)**, ГМу не показываются.
- Если у волшебника несколько владельцев-игроков, диалог появится у каждого.
